# Семейный архив

Статический сайт на HTML, CSS и JavaScript. Для просмотра откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Подключение Telegram

В `config.js` укажите `telegramBot` — имя вашего бота без `@`. Три кнопки передают боту параметры `/start archive_1`, `/start archive_5` и `/start archive_all`. До подключения бота они открывают сообщение о предстоящем запуске.

Цены на странице: 25, 75 и 150 Telegram Stars. Сам сайт не принимает оплату и не выдаёт видео. Обработку параметров, оплату и выдачу соответствующих семейных видео нужно реализовать в будущем Telegram-боте. Архив «Все видео» означает все видео в текущем архиве.

## Публикация

Загрузите `index.html`, `style.css`, `config.js`, `script.js` и папку `pic` на любой статический хостинг с HTTPS. Секреты и токен бота в файлы сайта добавлять нельзя — настройки сайта публичны.

Изображения: `pic/family-01.jpg` и `pic/family-02.jpg`. Оригиналы сохранены в корне проекта.
